# Univo (ClassFlow – Academic Companion)

A student dashboard for college: notices, study notes, assignments, timetable, exams,
academic calendar, attendance tracker (75% rule), CGPA calculator and a demo AI assistant.

Everything shown today is **sample data** saved in the browser (localStorage).
Real accounts (Supabase) and the college API are not connected yet.

## Tech stack

- React with JavaScript (JSX)
- Vite + TanStack Router / TanStack Start
- Tailwind CSS
- Planned: Supabase (login, profiles, preferences) and a college API (official academic data)

## Run it

```sh
bun install      # or: npm install
bun run dev      # or: npm run dev
bun run test     # or: npm run test
```

## Where things are

```text
src/
  routes/           one file per page (the file name is the URL; this is how the router works)
  components/
    ui/             basic building blocks (button, input, dialog...)
    common/         small reusable pieces (cards, chips, page header)
    layout/         sidebar, top bar, search
    brand/          logo
    auth/           layout shared by login and register
    attendance/, cgpa/, dashboard/   pieces used by a single page
  data/
    sample-data.js  the demo data used by every page (replaced by the college API later)
    data-shapes.js  comment-only reference: what each data object contains
    nav.js          sidebar menu items
    ai-demo.js      sample prompts and answers for the demo assistant
  utils/            plain helper functions
    academics.js    attendance and CGPA calculations (tested in academics.test.js)
    dates.js, selectors.js, tones.js, seo.js, class-names.js
  storage/          saving data in the browser (localStorage)
    persisted-store.js  the small helper that saves one piece of data
    app-stores.js       the stores used by the app (profile, notes, assignments...)
  error-handling/   error page and error logging used by the server entry
  routeTree.gen.ts  generated by the router tool, do not edit (the only TypeScript file)
```

## Notes for developers

- Saved browser data uses the key prefix `campuspulse:` (kept from the old name so existing saved notes still load).
- `routeTree.gen.ts` and `tsconfig.json` stay because the router generates that file in TypeScript.
- `bun.lock` was not regenerated after removing unused libraries; run `bun install` once.
