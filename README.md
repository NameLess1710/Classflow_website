# Classflow Academic Companion

Build a responsive, modern student-focused web application called CampusPulse AI.

It is an AI-powered academic information management platform for college students.

-Technology:

React.js

Tailwind CSS

Responsive design for mobile, tablet and laptop

-Design requirements:

Modern, professional academic dashboard.

Create a professional logo with the name CampusPulse AI.

Make the interface beginner-friendly and easy to navigate.

-Use this colour palette:

Main background: #0B1020

Sidebar and cards: #151D32

Primary purple: #8B5CF6

Accent cyan: #22D3EE

Main text: #F8FAFC

Secondary text: #94A3B8

Borders: #273449

Use subtle gradients for important buttons, rounded cards, soft shadows and clean typography.

Ensure all text is readable and maintain good contrast. Apply the theme consistently to every page, including login, dashboard, notices, notes, assignments, timetable and AI chatbot.

Keep the interface modern, clean and professional. Avoid excessive glow effects.

-Create these pages:

Login page

Student registration page

Dashboard

Notices

Study Notes

Assignments

Timetable

Exam Information

Academic Calendar

Ask CampusPulse AI chatbot

Profile and Settings

Attendance Tracker (with 75% rule safe-to-miss / must-attend calculator)

CGPA & Grade Calculator (with target goal simulator)

-Dashboard requirements:

Welcome message for the student.

Upcoming deadlines.

Recent college notices.

Today's timetable.

Recent uploaded documents.

Quick access to all modules.

Attendance quick overview widget.

-Important:

Build the frontend first.

Use realistic sample data for demonstration.

Make navigation buttons functional.

Do not create a separate admin website.

Do not build fake AI functionality. Keep AI features clearly marked as demo placeholders with realistic interactive sample prompts until a real backend is connected.

Use browser localStorage persistence so added notes, completed assignments, and profile updates persist across reloads.

Organise the code into reusable components and separate pages.
